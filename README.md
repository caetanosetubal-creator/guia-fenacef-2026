# Guia do Participante – Simpósio FENACEF 2026

Site oficial de apoio ao Simpósio FENACEF 2026, realizado de 9 a 12 de novembro no Mabu Thermas Grand Resort, Foz do Iguaçu.

## Publicação
- Projeto Vercel existente: `simposio-fenacef-2026`
- Endereço: https://simposio-fenacef-2026.vercel.app/
- Código-fonte publicado: `index.html`
- Construção estática: `npm run build` (gera `public/`)
- O arquivo `build.js` copia o guia e preserva os dois arquivos oficiais de marca da implantação anterior.

## Atualização de novembro de 2026
- Programação de 9, 10, 11 e 12 de novembro conforme o caderno oficial.
- 358 inscritos, apresentados por delegação e entidade, sem nomes individuais.
- Oito links de transmissão no YouTube inseridos nas atividades correspondentes.

Este repositório foi preparado a partir da versão atual do guia, evitando restaurar versões antigas. A associação ao projeto existente foi realizada em 11/11/2026.
